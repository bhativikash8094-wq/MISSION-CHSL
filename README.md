# 🚀 MISSION CHSL — 45 Days of Consistency

> **45 days. One mission. No excuses.**

MISSION CHSL is a web-based **45-day consistency and preparation tracker** built to help students stay disciplined, track their daily progress, and keep their preparation organized.

🌐 **Live Project:** https://www.missionchsl.com
📦 **Repository:** https://github.com/bhativikash8094-wq/MISSION-CHSL

---

## 🎯 Purpose

Preparing for a competitive exam is not only about studying more — it is about showing up every day.

**MISSION CHSL** turns preparation into a 45-day consistency challenge where progress can be tracked day by day.

The goal is simple:

**Start → Stay Consistent → Track Progress → Complete 45 Days**

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/bhativikash8094-wq/MISSION-CHSL.git
```

### 2. Open the project

```bash
cd MISSION-CHSL
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create your environment file using `.env.example` and add the required values.

### 5. Start the development server

```bash
npm run dev
```

The project will start using Vite.

---
